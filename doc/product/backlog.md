# 产品 Backlog

## 产品目标

让访客能快速阅读博主的文章，让博主能安全、稳定地编辑和发布内容。

## Sprint 0：工程基线

Sprint 目标：建立一条人与 AI 都能重复执行的开发闭环。

- [x] 建立 AI 项目约束、代码和 Git 规范。
- [ ] 建立 Go + React 行走骨架和健康检查。
- [ ] 使用现有镜像建立 MySQL 本地环境。
- [ ] 建立统一本地质量命令和 CI。
- [ ] 建立 Issue/PR 模板。

## Sprint 1：最小可发布内容链路

Sprint 目标：访客可查看已发布的文章，博主可在受保护的入口创建并发布文章。

1. 初始数据库模型与可回滚迁移。
2. 访客查看已发布文章列表。
3. 访客通过稳定 slug 查看文章详情。
4. 单管理员安全登录。
5. 管理员创建草稿并发布文章。

## 暂不进入 MVP

多用户、评论、搜索、图床、标签/分类、RSS、统计仪表盘、微服务和 Kubernetes。
