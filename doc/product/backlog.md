# 产品 Backlog

## 产品目标

让访客能快速阅读博主的文章，让博主能安全、稳定地编辑和发布内容。

## Sprint 0：工程基线

Sprint 目标：建立一条人与 AI 都能重复执行的开发闭环。

- [x] 建立 AI 项目约束、代码和 Git 规范。
- [x] 建立 Go + React 行走骨架和健康检查。
- [x] 使用现有镜像建立 MySQL 本地环境。
- [x] 建立统一本地质量命令和 PR CI。
- [x] 建立 Issue/PR 模板。
- [x] 配置远程 `main` 分支保护。
- [x] 用 ADR 固化完整技术选型并关闭实施前开放项。
- [x] 建立合并后的构建、部署、健康检查和回滚流水线。
- [x] 在 `ssh tencent` 服务器完成部署与回滚演练。

Sprint 0 已于 2026-09-30 完成验收，证据见 [`Sprint 0 验收记录`](../engineering/sprint-0-acceptance.md)。ICP备案、正式 DNS/TLS 和公网开放属于后续上线门禁，不阻塞 Sprint 1 开发。

## Sprint 1：最小可发布内容链路

Sprint 目标：访客可查看已发布的文章，博主可在受保护的入口创建并发布文章。

1. [x] 初始数据库模型与可回滚迁移。
2. [x] 访客查看已发布文章列表。
3. [x] 访客通过稳定 slug 查看文章详情。
4. [x] 单管理员安全登录。
5. [x] 管理员创建草稿并发布文章。
6. [x] 管理员上传图片并插入文章。

Sprint 1 已于 2026-10-01 完成验收，证据见 [`Sprint 1 验收记录`](../engineering/sprint-1-acceptance.md)。

## Sprint 2：内容管理与阅读体验

Sprint 目标：博主可维护文章全生命周期及分类标签，访客可按分类浏览并获得适合技术文章的阅读体验。

1. [x] 管理员创建、编辑和删除文章，已发布文章也可编辑。
2. [x] 每篇文章属于一个分类并可关联多个标签，前台支持分类展示和筛选。
3. [x] 技术文章支持带行号的按语言语法高亮代码块、Mermaid 图表、数学公式和可点击大纲。
4. [x] Header 中暂时移除尚无页面的“关于”入口。

Sprint 2 已于 2026-10-02 完成验收，详细范围见 [`Sprint 2 开发计划`](../engineering/sprint-2-plan.md)，证据见 [`Sprint 2 验收记录`](../engineering/sprint-2-acceptance.md)。

## Sprint 3：沉浸式阅读氛围

Sprint 目标：访客浏览博客前台时可伴随固定背景音乐阅读，并能随时暂停或继续播放。

1. [x] 前台页面默认尝试以 5% 音量循环播放背景音乐；若被浏览器拦截，则在访客首次点击页面时开始播放，并提供始终可用的暂停/继续控制。

详细范围见 [`Sprint 3 开发计划`](../engineering/sprint-3-plan.md)。

Sprint 3 已于 2026-10-02 完成验收，证据见 [`Sprint 3 验收记录`](../engineering/sprint-3-acceptance.md)。

## Sprint 4：博客前台视觉原型

Sprint 目标：为现有博客前台提出适合文章浏览和长文阅读的瑞士风格视觉方案，先以可评审原型确认方向。

1. [ ] 为文章列表与文章详情制作桌面和手机布局原型，展示现有的分类、标签、文章大纲和技术内容。

详细范围与验收标准见 [`Sprint 4 原型计划`](../engineering/sprint-4-plan.md)。范围已由用户确认；本 Sprint 暂不实施生产前端页面。

## Sprint 5：按瑞士风格原型重构博客前台

Sprint 目标：将已确认的文章列表与详情原型应用到真实前台，保持现有阅读与浏览能力，并通过现有流水线发布。

1. [x] 按原型重构公开文章列表和详情的桌面、手机布局，保留分类、分页、Markdown、大纲、背景音乐与错误状态。
2. [ ] 在前端检查通过后合并到 `main`，由现有发布流水线部署并验证健康状态。

范围与验收标准见 [`Sprint 5 开发计划`](../engineering/sprint-5-plan.md)。用户已确认 Sprint 4 原型并要求实施、提交、合并与部署。
