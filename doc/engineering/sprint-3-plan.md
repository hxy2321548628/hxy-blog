# Sprint 3 开发计划

- 日期：2026-10-02
- 状态：开发完成，待用户验收
- Sprint 目标：访客浏览博客前台时可伴随固定背景音乐阅读，并能随时暂停或继续播放。

## 已确认的产品决策

- 背景音乐固定为《Shade of Light》，使用用户提供并确认可公开使用的 MP3 文件。
- 博客前台页面加载后立即尝试自动播放；若浏览器阻止有声自动播放，则在访客首次点击页面任意位置时开始播放。
- 默认音量为 5%，曲目播放结束后自动循环。
- 前台提供始终可见且可通过键盘操作的播放/暂停按钮。
- React SPA 的前台路由切换不重新开始曲目；进入管理页面时不播放背景音乐。
- 音频不预加载完整文件，避免约 12 MiB 的资源阻塞首屏加载。

## 非目标

- 不提供歌单、切歌、进度拖动、音量调节或歌曲信息面板。
- 不提供后台音频上传、曲目配置或数据库存储。
- 不绕过浏览器自动播放策略，也不保证所有浏览器首次访问时都能直接发声。
- 不在管理端登录、文章管理或编辑页面播放背景音乐。
- 不新增第三方前端依赖，不修改后端 API、数据库 Schema 或部署镜像。

## 故事与验收标准

### 故事 1：前台背景音乐

- Given 访客打开任一前台页面，When 浏览器允许有声自动播放，Then 《Shade of Light》以 5% 音量开始播放并在结束后循环。
- Given 浏览器阻止自动播放，When 页面加载完成，Then 页面正常展示且播放器保持可操作；When 访客首次点击页面任意位置，Then 音乐开始播放且不会重复注册全页点击监听。
- Given 音乐正在播放，When 访客点击暂停，Then 音乐立即暂停；When 再次点击，Then 从暂停位置继续播放。
- Given 音乐正在播放，When 访客在文章列表和详情之间切换，Then 播放不中断且不从头开始。
- Given 访客进入登录页或管理页面，Then 背景音乐不播放且不展示前台播放器。
- Given 访客仅使用键盘或辅助技术，Then 控件具有明确的播放状态、可访问名称和可见焦点。

## 依赖与风险

- 使用浏览器原生 `<audio>` 能力，不新增运行时依赖。
- 主流浏览器通常阻止首次访问时未经用户交互的有声自动播放；实现必须处理 `play()` 被拒绝的 Promise，并保留手动播放入口。
- MP3 约 12 MiB；播放器使用 `preload="none"`，但开始播放后仍会产生对应流量，生产静态服务需要支持音频请求。
- 音频作为公开静态资源随 Web 镜像发布；发布前提是用户拥有公开传播该音频的权利。

## 验证命令

- `npm --prefix src/web test`
- `make check`
- 在本地浏览器验证自动播放允许/阻止两种情况、10% 默认音量、循环、暂停/继续、前台路由切换和管理页隔离。
