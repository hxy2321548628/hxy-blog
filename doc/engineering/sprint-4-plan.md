# Sprint 4 原型计划

- 日期：2026-10-09
- 状态：原型已完成，待用户评审
- Sprint 目标：用可评审原型确定博客前台的瑞士风格视觉方向，同时保持文章浏览和长文阅读的清晰度。

## 目标与范围

- 目标用户：浏览文章列表、按分类查找内容并阅读技术长文的访客。
- 本次只交付前台视觉原型，覆盖文章列表和文章详情；各有桌面与手机布局。
- 原型沿用现有信息结构：文章标题、发布日期、分类、标签、分页、文章正文与大纲。示例内容只作展示。
- 视觉方向采用明确的网格、强弱分明的字级、充足留白与克制的强调色；正文宽度、行距和代码块优先服务阅读。

## 非目标

- 不修改当前 React 页面、后端 API、数据库 Schema、部署配置或管理端。
- 不新增搜索、评论、关于页等尚未实现的功能。
- 不在本次确认生产视觉风格或直接发布上线；原型评审后再安排实现故事。

## 故事与验收标准

### 故事 1：博客前台视觉原型

- Given 访客查看文章列表原型，When 以桌面或手机宽度浏览，Then 能辨认站点标识、文章标题、日期、分类、标签和分类入口；信息不会横向溢出。
- Given 访客查看文章详情原型，When 阅读长标题、正文、代码与大纲，Then 正文保持清晰的阅读宽度、字级和行距，长代码仍可查看。
- Given 原型展示桌面和手机状态，When 比较页面，Then 主要内容的阅读顺序一致，手机布局不依赖桌面侧栏。
- Given 评审原型，When 对照现有前台能力，Then 不会将尚未实现的功能表现为已可用入口。

## 风险与依赖

- 当前生产样式是暖色纸张风格，仓库中另有白底蓝色视觉手册；新原型会与两者明显不同，需要评审后再决定是否替换生产样式或更新手册。
- 仅使用仓库现有能力制作静态原型，不引入新依赖；不涉及数据迁移、鉴权或外部服务。
- 用户已确认页面范围为文章列表与文章详情，各含桌面和手机布局。
